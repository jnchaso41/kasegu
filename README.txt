KASEGU iPhone対応Webアプリ

【インストール方法】
このZIPを解凍し、index.html / manifest.json / sw.js をHTTPS対応のWebホスティングへアップロードしてください（例：GitHub Pages）。公開されたHTTPS URLをiPhoneのSafariで開き、共有ボタン→「ホーム画面に追加」→「追加」を選択すると、ホーム画面からアプリのように起動できます。

【機能】
・案件／見込み客管理（サービス、見積金額、進捗、期限、メモ）
・入金記録と月間売上集計
・月10万円などの目標設定と達成率
・営業提案文の作成・コピー
・JSONバックアップと復元

【注意】
データは同じブラウザ内に保存され、端末間同期はありません。ブラウザデータ削除で消える可能性があるため、定期的にバックアップしてください。仕事の仲介・顧客への送信・決済・報酬保証はありません。案件獲得、契約、納品、請求、入金確認は外部サービス等で行ってください。
